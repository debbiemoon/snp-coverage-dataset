# Changelog

## v1.0.0 (2026-10-20)

First public release.

- Presence data for 9 consumer DNA test versions: 23andMe v3, v4, and v5; AncestryDNA v2 (2020 download); AncestryDNA (Mar 2026); MyHeritage (2026); tellmeGen; FamilyTreeDNA; and StrateGene (testing era, 2022).
- `snp-coverage-all-rsids-v1.0.0.csv.gz`: 1,743,562 IDs (rsIDs and 23andMe `i` IDs).
- `snp-coverage-genetic-lifehacks-v1.0.0.csv`: 2,171 variants from 413 Genetic Lifehacks articles, with per-test verdicts.
- `article-coverage-summary-v1.0.0.csv`: per-article coverage for each test.
- `datasets.csv`: details for each test column.
- Files last checked October 2026.
